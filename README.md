# LM Studio

### Discover, download, and run local LLMs with ease

LM Studio is the most polished local LLM desktop app available. Browse thousands of models from Hugging Face, download them with one click, and run them through a ChatGPT-like interface or local API server.

<br>

---

## Features

| | |
|:---|:---|
| **Model Discovery** | Browse and filter thousands of GGUF models from Hugging Face directly |
| **Local API Server** | Spin up an OpenAI-compatible server for use with any application |
| **GPU Offloading** | Intelligently splits model layers between CPU and GPU for max speed |
| **Chat Interface** | Beautiful, feature-rich chat UI with system prompts and parameter control |
